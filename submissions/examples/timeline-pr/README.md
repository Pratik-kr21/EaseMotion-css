# Animated Glowing Timeline

**What does this do?**
A beautifully animated vertical timeline component featuring gradient lines, pulsing active dots, and smooth hover translations.

**How is it used?**
Wrap your events in `.timeline`. For each event, use `.timeline-item` containing a `.timeline-dot` and `.timeline-content`. Use `.timeline-dot-active` for a continuous pulse animation.

**Why is it useful?**
Timelines are essential for roadmaps, changelogs, and history sections. This component elevates the standard timeline into a premium dark-mode experience with interactive glow effects and fluid micro-animations.
