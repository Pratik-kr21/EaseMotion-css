# Premium Responsive Stepper Indicator

**What does this do?**
A premium multi-step progress indicator that animates the line between steps and cleanly shifts to a vertical layout on mobile devices.

**How is it used?**
Wrap steps in `.stepper`. Use `.step` for each step, containing a `.step-icon` and `.step-content`. Place a `.step-line` inside all steps except the last one. Use `.step-completed` or `.step-active` to reflect progress.

**Why is it useful?**
Steppers are critical for complex forms, checkout flows, and onboarding. This component brings EaseMotion's fluid design language to step indicators, with animated gradient fills, pulsing shadows, and a seamless responsive transition to mobile without requiring any JavaScript.
