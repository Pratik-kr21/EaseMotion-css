# Premium Glassmorphism Pricing Cards

**What does this do?**
A set of premium, glassmorphism-styled pricing cards featuring hover animations, gradient accents, and a distinct "most popular" tier highlight.

**How is it used?**
```html
<div class="pricing-grid">
  <div class="pricing-card pricing-card-popular">
    <div class="pricing-badge">Most Popular</div>
    <h3 class="pricing-tier">Professional</h3>
    <div class="pricing-price">$29<span class="pricing-period">/mo</span></div>
    <ul class="pricing-features">
      <li>Unlimited Projects</li>
    </ul>
    <button class="pricing-btn pricing-btn-primary">Upgrade to Pro</button>
  </div>
</div>
```

**Why is it useful?**
Pricing sections are critical for SaaS applications. This component provides a highly polished, modern dark-mode aesthetic utilizing backdrop filters and subtle scaling transitions that fit perfectly into EaseMotion's premium look.
